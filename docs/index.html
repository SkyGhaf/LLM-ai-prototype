Over de techniek

Wat er onder de motorkap van deze AI-kamerassistent gebeurt.

🧭 Vaste workflow-orchestratie

Python stuurt een 6-staps gesprek aan (begroeting → vragen → samenvatting → zoeken → tonen → feedback) als state machine. Betrouwbaar en voorspelbaar.

🗣️ LLM voor tekstbegrip

Een lokaal taalmodel (llama3.2 via Ollama) haalt criteria uit vrije tekst — "voor 2 personen onder de 130" wordt automatisch herkend.

🔎 RAG met vectordatabase

Kamerbeschrijvingen staan als embeddings in een FAISS-vectorstore, zodat sfeerwensen ("rust", "uitzicht", "wellness") semantisch gematcht worden.

🛠️ Tools & validatie

LangChain-tools filteren, rangschikken en valideren elke aanbeveling vóór ze getoond wordt — geen verzonnen prijzen of kamers.
